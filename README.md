# 📖 Overview

The **Smart Traffic Fine Management System** is a second-year B.Tech OOP project developed in **C++**.

The application provides an efficient way to manage traffic fines by maintaining driver records, vehicle information, violation history, payment records, and administrative reports.

The project is built using **Object-Oriented Programming principles** including encapsulation, inheritance, polymorphism, constructors, and file handling.

A modern **web interface** will also be integrated in future versions while keeping the C++ backend logic.

# ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/harshu-belal/Smart-Traffic-Fine-Management-System.git
```

Move into the project

```bash
cd Smart-Traffic-Fine-Management-System
```

Compile

```bash
g++ *.cpp -o SmartTrafficFineSystem
```

Run

Windows

```bash
SmartTrafficFineSystem.exe
```

Linux

```bash
./SmartTrafficFineSystem
```
